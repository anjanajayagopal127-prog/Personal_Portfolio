# Anjana P --- Student Portfolio

A personal portfolio website for **Anjana P**, a second-year B.Tech
student at **Jawaharlal College of Engineering and Technology**. The
site presents an introduction, education, beginner-level technical
skills, learning projects, and contact options.

## About the Project

This portfolio was created to practise front-end web development and to
showcase academic learning and student projects in a single responsive
website.

### Features

-   Responsive layout for desktop and mobile screens
-   Light and dark theme toggle
-   Animated role text in the hero section
-   About-me and education sections
-   Skill bars and technical-skill tags
-   Project cards with category filters
-   Contact form with basic validation
-   Contact form opens the visitor's default email app
-   Scroll progress indicator, active navigation links, and back-to-top
    button
-   Subtle section-reveal animations
-   My learning journey timeline with learning milestones and future goals

## Technologies Used

-   **HTML5** --- page structure and content
-   **CSS3** --- styling, layout, responsive design, animations, and
    themes
-   **JavaScript** --- theme switching, mobile menu, project filtering,
    skill animations, form validation, and other interactions
-   **Google Fonts** --- DM Sans and Sora

## Getting Started

No build tools or package installation are required. The portfolio is a
standalone HTML file.

1.  Download or clone the project files.
2.  Keep `index.html` in a folder on your device.
3.  Open the file in a web browser to view the website.
4.  To edit it, open the HTML file in Visual Studio Code, Acode, or
    another code editor.
5.  Save your changes and refresh the browser.

## Customisation

Before publishing, review these items in `index.html`:

-   **Email address:** Replace `you@example.com` with your real email
    address in both the contact section and the `MY_EMAIL` JavaScript
    constant. The contact form uses a `mailto:` link, so it opens the
    visitor's configured email application; it does not send messages
    through a server.
-   **GitHub and LinkedIn:** Add your profile URLs if you want to
    display them.
-   **Projects:** Update descriptions and links to match projects you
    have actually built.
-   **Education:** Add your B.Tech branch, expected graduation year, or
    other details if you wish.
-   **Skills:** Adjust the listed skills and percentages to accurately
    reflect your current level.
-   **Fonts:** The page loads DM Sans and Sora from Google Fonts; a
    system sans-serif fallback is provided.
